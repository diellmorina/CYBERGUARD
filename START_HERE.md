## 💾 Your Data

### Where is it stored?
- **In your browser's localStorage**
- **Not on any server**
- **Completely private**

### What data is stored?
- Your profile name
- Lessons completed
- Quiz attempts and scores
- Achievements earned
- XP and level
- Settings preferences

### Can I backup my progress?
- **Yes!** Use Settings → Export Progress
- Download as JSON file
- Import anytime using Import function

### Is my data safe?
- **Yes!** All data stays in your browser
- No external servers
- No tracking
- No cookies
- 100% private

### App not loading?
1. Refresh the page

3. Try different browser
4. Check JavaScript is enabled

### Data not saving?
1. Check localStorage is enabled
2. Try different browser

4. Export data first (backup)

2. Clear browser cache
3. Check browser console (F12)
